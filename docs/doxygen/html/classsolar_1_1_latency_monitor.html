Detailed Description

Measures and aggregates end-to-end latency across the processing pipeline.

Tracks timestamps per frame_id and computes:

  • Total latency (capture → actuate)
  • Vision latency (capture → estimate)
  • Control latency (estimate → control)
  • Actuation latency (control → actuate)

Uses std::chrono::steady_clock for monotonic timing. Thread-safe (synchronization implemented in .cpp).
