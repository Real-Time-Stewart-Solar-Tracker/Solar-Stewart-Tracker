Detailed Description

Thread-safe logging utility for runtime diagnostics and latency tracing.

Provides:

  • Human-readable info/warn/error logging
  • Timestamped stage markers for latency analysis

Uses std::chrono::steady_clock for monotonic timing. If a file path is provided, logs are written to both console and file.
