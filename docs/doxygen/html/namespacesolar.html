enum class solar::TrackerState
strong

High-level state machine for the solar tracking system.

Represents the operational mode of the SystemManager.

Enumerator
IDLE 

System inactive and not running.

STARTUP 

System initialization in progress.

NEUTRAL 

Platform moving to neutral reference position.

SEARCHING 

Searching for the sun (no reliable estimate yet).

TRACKING 

Actively tracking the sun using vision feedback.

MANUAL 

Manual control mode (user-defined setpoint).

STOPPING 

Graceful shutdown in progress.

FAULT 

Fault condition detected.
