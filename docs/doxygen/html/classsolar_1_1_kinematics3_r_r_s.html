Detailed Description

Inverse kinematics solver for a 3-RRS platform.

Converts platform tilt/pan setpoints into three actuator targets (servo angles) using deterministic 3-RRS inverse kinematics.

Pure computation layer:

  • No hardware access
  • No internal threads
  • Emits ActuatorCommand via callback
