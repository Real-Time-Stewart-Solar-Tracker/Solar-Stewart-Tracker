# 3RRS 视觉追踪系统 - 完整版本保存

本文件夹包含树莓派5 3RRS并联机构视觉追踪系统的完整程序。

## 📁 文件说明

### 主程序

#### `main_tracker.py`
完整的视觉追踪系统主程序，包含：
- **视觉检测**：使用OpenCV HSV颜色空间检测红色目标
- **PID控制**：Kp=0.3，响应快速，最大倾斜35°
- **3RRS逆运动学**：完全对齐sun211.m的算法
- **舵机控制**：通过PCA9685驱动三个舵机
- **平滑运动**：低通滤波插值，平滑系数0.15

**关键特性**：
- 舵机中位：90°（逆运动学计算）
- 初始化位置：60°（避免机构损坏）
- 退出位置：60°（安全位置）
- 控制频率：50Hz

**运行命令**：
```bash
# 无显示模式（SSH连接）
python3 main_tracker.py --no-display

# 带显示模式（本地运行）
python3 main_tracker.py

# 演示模式（自动画圆）
python3 main_tracker.py --demo
```

简单舵机测试程序

**可调参数**：
- `min_angle = 0`：最小角度
- `max_angle = 60`：最大角度
- `delay = 0.05`：运动速度（秒）

## 🔧 硬件连接

### PCA9685 舵机驱动板
| 树莓派 | PCA9685 |
|--------|---------|
| GPIO2 (SDA) | SDA |
| GPIO3 (SCL) | SCL |
| GND | GND |

### 舵机电源
| PCA9685 | 电源 |
|---------|------|
| V+ | 5~6V 正极 |
| GND | 负极 |

### 舵机连接
| PCA9685通道 | 舵机编号 |
|-------------|----------|
| 0 | 舵机1 |
| 1 | 舵机2 |
| 2 | 舵机3 |

- CSI摄像头连接到树莓派CSI接口

## 🚀 使用流程

1. **上传程序到树莓派**：
   ```bash
   scp main_tracker.py pi@<树莓派IP>:/home/pi/
   ```

2. **SSH连接到树莓派**：
   ```bash
   ssh pi@<树莓派IP>
   ```

3. **运行程序**：
   ```bash
   python3 /home/pi/main_tracker.py --no-display
   ```

4. **测试追踪**：
   - 使用红色物体（红色瓶盖、红纸等）
   - 移动红色物体观察舵机响应

5. **停止程序**：
   - 按 `Ctrl+C`
   - 舵机会自动回到60°安全位置

---

## ⚠️ 注意事项

1. **目标检测**：系统检测**红色物体**，不是手电筒光
2. **初始位置**：程序启动时舵机归到60°，不会先到90°
3. **机构保护**：确保60°是机构的安全位置
4. **平滑运动**：舵机会平滑过渡，不会突然跳动
5. **摄像头**：如果摄像头灯不亮，尝试重启树莓派或清理占用进程
